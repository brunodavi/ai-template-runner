# AI Template Runner

Simple AI workflows based on Markdown templates.

## Installation

Install directly from GitHub using "uv":

```bash
uv tool install git+https://github.com/brunodavi/ai-template-runner.git
```

## Development
Clone the repository:

```bash
git clone https://github.com/brunodavi/ai-template-runner.git
cd ai-template-runner
```

Install the project and its dependencies:

```bash
uv sync
```

Run the project in the development environment:

```bash
uv run ait
```

## Status

AIT is an early-stage project. Its initial goal is to explore simple AI workflows based on Markdown templates.
